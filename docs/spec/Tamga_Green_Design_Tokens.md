## Типографика

| Роль | Шрифт | Где использовать |
|---|---|---|
| Display | Fraunces (500/600/700) | H1–H3, hero, элементы печати/верификации |
| Body / UI | Inter (400/500/600/700) | Весь интерфейс, формы, таблицы |
| Utility / Mono | IBM Plex Mono (400/500) | Цены, SKU, остатки, таймстемпы, лейблы |

Шкала: H1 48/56, H2 34/40, H3 22/28, Body L 17/26, Body M 15/24, Caption 13/18, Mono 13/18 (размер/line-height в px, вес 600 для заголовков, 400 для текста).

## Интервалы (шаг 4px)

`4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96` px — токены `sp-1`…`sp-9`.

## Сетка

- Desktop (≥1200px): 12 колонок, gutter 24px, контейнер max-width 1280px
- Tablet (768–1199px): 8 колонок, gutter 16px
- Mobile (<768px): 4 колонки, gutter 8px

## Радиусы

`sm 4px` (инпуты) · `md 8px` (кнопки, карточки) · `lg 16px` (модалки, hero-блоки) · `full 999px` (бейджи, пилюли)

## Тени (тёплый тон вместо чистого чёрного, на основе `--ink`)

- `shadow-sm`: `0 1px 2px rgba(30,33,25,.08), 0 1px 1px rgba(30,33,25,.04)` — карточки в списках
- `shadow-md`: `0 4px 10px rgba(30,33,25,.10), 0 2px 4px rgba(30,33,25,.06)` — всплывающие панели
- `shadow-lg`: `0 16px 32px rgba(30,33,25,.16), 0 4px 10px rgba(30,33,25,.08)` — модалки, hover-приподнятость карточек

## Анимация

- Микровзаимодействия: 150–250мс, `cubic-bezier(.4,0,.2,1)`
- Loading-индикатор — фирменный элемент «печать» (seal), вращение 0.7–2.4с linear, а не нейтральный спиннер
- Обязательна поддержка `prefers-reduced-motion: reduce`

## Сигнатурный элемент

**Печать (Seal)** — круглый штамп с мотивом листа, отсылающий к «тамге» как historically родовому клейму подлинности. Используется как: бейдж верификации поставщика, состояние загрузки (вращение), декоративный маркер бренда в шапке/hero. Не тиражировать в декоративных целях — только там, где несёт смысл подтверждения/статуса.
